## Mathematical Semantics

Scaled dot-product attention forward pass.

Tensor layout: Q, K, V, O are [batch, heads, seq, head_dim] contiguous row-major.

For each b in [0,batch), h in [0,heads), i in [0,seq):
  For each j in [0,seq): score(i,j) = sum_d(Q[b,h,i,d] * K[b,h,j,d]) * scale
  m_i = max_j score(i,j)
  For each j: p(i,j) = exp(score(i,j) - m_i) / sum_t exp(score(i,t) - m_i)
  For each d: O[b,h,i,d] = sum_j p(i,j) * V[b,h,j,d]

Numerical stability: always subtract row maximum before exponentiation in softmax.
