qualified, but the first Agent candidate did not compile under the verified

## 1. Phase 17-A starting point

The target is the real Megatron
`DotProductAttention.forward` native local core, not generic Dense Fused
Attention. The boundary is dense/no-mask/p=0 forward only:

`scaled QK^T -> FP32-behavior softmax -> dropout identity -> PV -> output layout`.

QKV/output projection GEMMs, rotary, masks, nonzero dropout, TE, flash-attn,
and backward optimization remain excluded.
