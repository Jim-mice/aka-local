# Scientific Promotion Gate Registry

`source identity → replay contract → candidate ABI/delivery → toolchain →
semantic correctness → distributed completeness when applicable → shared
performance scope → read-only environment provenance → reference stability →
candidate stability → promotion policy → promotion NSYS → incumbent manifest
→ deterministic replay → integration`.

A later gate cannot compensate for a failed earlier one. Environment readiness
is an advisory pre-window check and never replaces campaign CV qualification.
All valid slow samples remain raw evidence.
