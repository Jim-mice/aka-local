# Phase 18-B.1 lesson

Agent candidate delivery metadata is an executable interface, not optional
documentation. A wrong symbol and a missing semantic marker are distinct
delivery failures and must be rejected before CUDA compilation. A hardened
prompt header plus machine-readable preflight reduced these to precise classes.
M3 then demonstrated the next distinct class: delivery/build success does not
imply semantic correctness. M4 passed correctness, but promotion still failed
closed because the frozen reference CV gate failed for the two-empty expert
distribution. Reference instability is a first-class blocker; no favorable
subset or aggregate score may bypass it.
