# Agent operating contract

Query only the compact context needed for the selected campaign. Start with operator, platform, backend, incumbent, frontier, recent canonical memories, and scoped knowledge. Do not treat live/runtime events as GPU evidence. Agent hypotheses are not supervisor decisions; only deterministic evaluation may create promotion decisions. Preserve provenance and hardware/backend scope.

Before every experiment, refresh the local knowledge/context snapshot; never rely on cross-conversation memory. When canonical knowledge or experiment records are produced, preserve the technical original and create/update the `zh-CN` localization overlay. Translation is representation, not new evidence: preserve metrics, identifiers, code symbols, paths, hardware/backend names, shapes, and technical scope.
